# Job Application Tracker

A full-stack application that helps users manage job applications and receive AI-powered resume feedback.

## Features

- JWT Authentication
- User-specific application tracking
- Resume-to-job match scoring
- Skill gap analysis using Gemini AI
- PostgreSQL persistence

## Tech Stack

- Java
- Spring Boot
- Spring Security
- PostgreSQL
- Hibernate
- Gemini API
